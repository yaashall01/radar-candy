# Radar Candidatures

Extension Chrome pour suivre tes candidatures. Ouvre une offre et clique sur un des boutons de Radar pour enregistrer son titre, son lien et son statut.

## Installation dans Chrome

1. Clone ce dépôt ou télécharge-le depuis **Code → Download ZIP**, puis décompresse-le.
2. Ouvre `chrome://extensions` dans Chrome et active le **Mode développeur**.
3. Clique sur **Charger l’extension non empaquetée** et sélectionne le dossier contenant `manifest.json`.
4. Épingle **Radar Candidatures** depuis le menu Extensions de Chrome.

## Utilisation

- **Mes choix** permet d’ajouter, de renommer ou de retirer des boutons. Tu peux aussi choisir lesquels comptent comme candidature envoyée et régler ton objectif hebdomadaire.
- **Mes candidatures** ouvre le tableau avec les offres, leurs statuts et le compteur de la semaine.
- Choisir un autre statut pour une offre déjà enregistrée met à jour sa fiche.

Les offres et les réglages sont enregistrés localement dans Chrome. Le chargement de l’extension utilise les fichiers de ce dépôt directement.
